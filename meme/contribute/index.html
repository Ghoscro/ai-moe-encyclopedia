发现新梗？来补一页。

有趣的对话、值得记录的趣事，或你写的萌娘日常，都可以从这里投稿。

  1. 先在百科首页搜一下，看看有没有同名条目。
  2. 填好下面的内容，点击“去 GitHub 提交 PR”。首次投稿按 GitHub 提示创建 Fork。
  3. 提交后会检查格式，维护者审核合并后更新到网站。你可以在 PR 页面跟进进度。

暂时不会提交 PR？也可以在 GitHub 留一条新梗线索，一起整理。

“有出处的趣事”需要公开 HTTPS 来源，优先原公告、论文或原帖。
